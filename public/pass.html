完全版について

最終更新：2026-10-26

最初の 8 つの星は無料で遊べ、デイリーチャレンジも無料です。「完全版」を一度購入すると、9〜28 番目の星が解放されます。

星1〜8さらに 9〜28（全 28）
デイリーチャレンジ✔✔
Game Center ランキング（iOS）✔✔（購入は順位に影響しません）

iOS アプリ

アプリ内で App Store から購入します。買い切りでサブスクリプションはありません。価格は App Store に表示される現地価格に従います。機種変更したときは、同じ Apple ID で「⚙️ 設定 → 完全版 → 購入を復元」を押してください。

Web 版

Web 版は現在すべての星を無料で公開しています。今後 Web 版を有料化する場合は、価格と購入方法をこのページでお知らせします。Web 版のご注文は当社のオンライン販売代理店 Lemon Squeezy が販売者（Merchant of Record）として処理します。

App Store での購入と Web 版の購入は別扱いです。Web 版のキーは iOS アプリでは使えず、アプリ内の購入を Web 版に移すこともできません。

iOS 앱

앱 안에서 App Store로 구매하며, 한 번 구매로 영구 소장(구독 아님)입니다. 가격은 App Store에 표시되는 현지 가격을 따릅니다. 기기를 바꾸면 같은 Apple ID로 「⚙️ 설정 → 정식판 → 구매 복원」을 누르세요.

웹 버전

웹 버전은 현재 모든 행성을 무료로 공개하고 있습니다. 앞으로 웹 버전이 유료화되면 가격과 구매 방법을 이 페이지에 안내하며, 웹 주문은 온라인 리셀러 Lemon Squeezy가 판매자(Merchant of Record)로서 처리합니다.

App Store 구매와 웹 구매는 별개입니다. 웹 라이선스 키는 iOS 앱에서 쓸 수 없으며, 앱 내 구매를 웹 버전으로 옮길 수도 없습니다.
