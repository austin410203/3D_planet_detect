| 資料類型 | 用途 | 與使用者身分連結 | 用於追蹤 |

| 識別碼 → 裝置 ID | 第三方廣告、分析 | 否 | 否 |
| 使用資料 → 產品互動、廣告資料 | 第三方廣告、分析 | 否 | 否 |
